## 実装概要

独立イントロ「Gemini体験ラボ」を追加しました。質問・文章・画像・クイズの4体験で、プロンプトを組み立て、条件変更前後を比較し、別の題材に応用できます。Geminiは別タブで学習者が操作し、APIや自動送信は導入しません。

既存10章の番号・章題・実践課題、第1章の操作と進捗保存、hashルート、Pagesサブパス、CI成功後だけ公開するゲートを維持します。

## 教育設計上の判断

- 抽象説明から始めず、予想と操作から、条件変更・比較・解説・応用へ進む5段階。各段階の学習目的を表示し、途中から再挑戦できます。
- 操作成功（コピー）、実行自己申告、応用自己申告、固定理解チェックの最終回答を別記録。コピーで実行・理解済みにはしません。
- 学習者の入力文・回答・予想・振り返りは永続保存せず、既存章の保存キーとは独立したラボ記録だけを保存。保存拒否時も継続可能です。
- 生成結果の貼付欄と教材の固定チェックを区別。共通安全教材は出典・個人情報・利用条件・成果物確認の3問と即時理由表示。
- 関連章は第1・6・7・9章。準備中を維持し、ラボ完了を本編への条件にしません。
