## オリジナル素材と模擬表現

動画は新規の600×420 SVGをコード制作。第7章の柴犬/黄色い星エプロン/宇宙厨房という題材と画風を継承し、NanoArtの既存実装・データは変更しない。外部画像/Google画像/実動画/第三者の曲や録音素材なし。音程・リズムの固定ルールとWeb Audio発振器から短いフレーズを合成する。リポジトリに一括のライセンス指定はなく、本章追加をもって無制限の再配布許諾とは扱わない。

- 動画48条件はフレーム計算に反映する。顔や服を毎回AIで描き直す処理ではない。実時間の精密性/背景タブ精度/動画ファイル生成は保証しない。
- 不整合3課題は同じ時間位置・viewBox・倍率で正常例/失敗例を並べる。中盤の服の色＋模様、器具の有無、位置の差を実描画と同じ関数由来の文字で提示する。色だけを判断手段にしない。具体的な分類は回答確定後に表示。
- 予想は開くと固定し、再挑戦で現在の比較と再生を破棄。条件の実変更は関連体験だけ解除し、同一選択は保持する。過去の操作履歴を現在の正答としない。
- 音は8音・3.2〜6秒、3リズム/3音程列/3波形。ジャンルと楽器は簡略電子音であり、本格編曲/生楽器の再現やボーカル合成ではない。ボーカル条件は全文指示にだけ反映。
- 全音は低いmaster gainで制限。1run/1Contextと世代番号を管理し、replay/条件変更/非表示/離脱/unmountで音源停止/切断・timer解除・Context close。未完了resumeは世代と開始hashで除外し、旧音を復活させない。
- 音番号の視覚進行は目安で、実際の発音時刻/音声成功ではない。無音学習と実聴自己申告を別にする。APIの開始成功だけではスピーカー出力/音質を確認したことにしない。

## 採用案・保留案・互換性

第一希望は軽量な実動デモと正確な映像/音同期。採用は決定的フレーム描画と独自短音の個別プレイヤー。端末のAudioContext resume/出力遅延を吸収した精密同期の保証は困難なため、同期統合・動画への音声書出しは保留。個別比較でも演出を判断できる構成にし、UIにも限界を表示する。大容量動画/音源・外部ライブラリ・AI生成は追加しない。

専用v1キーに固定選択・版付き回答/履歴・本文fingerprintコピー・閲覧/実聴/実Gemini自己記録だけ保存。再生・予想・現在判断・比較表示・音声資源は非保存。章完了は既存progress:v1の公開IDへchapter-8だけ追加。個別初期化は専用記録/章8完了を別々に実施し、片側失敗も成功としない。全体初期化は従来どおり章完了だけ。保存拒否時には画面内で続行し、再読み込みで旧記録が戻る可能性を伝える。

再利用可能なのは純粋な時間→フレーム関数、同時刻の比較、音源の世代ガード、本文対応copy。今回他プロジェクトへの移植や既存章の全面再設計は行わない。
