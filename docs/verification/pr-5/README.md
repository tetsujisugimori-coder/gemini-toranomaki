## 見つかった問題と修正

選択中の「モデル選択」を再タップすると、selected stateが変わらずEffectが実行されないため説明へフォーカスが移らない。375×812の修正前では、初回は説明見出しの上端が390px、再タップ後は939pxで画面外となった。押しても説明が開かないように見え、入口を探索し直す際に見失いやすい。

同じ選択の場合も説明へフォーカスを移動し、説明見出しの直後に「入口の選択へ戻る」を追加。戻る操作は直前の入口へフォーカスを戻し、次のTabで別の入口に進める。探索数は再選択で増えない。元のIssue、章構成、保存形式、既存完了条件は変更していない。
